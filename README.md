# Patterns — паттерны решения алгоритмических задач

## Как устроена каждая тема

Каждая папка — один паттерн:

| Файл | Содержание |
|---|---|
| `README.md` | Суть паттерна, признаки в условии, шаблоны кода, разбор задач, типичные ошибки |
| `*.py` | Решения задач — по одному файлу на задачу |
| `test_*.py` | Тесты (`pytest`), включая сверку с полным перебором |

Названия паттернов даны на английском (так они называются в литературе),
в скобках — русский вариант.
